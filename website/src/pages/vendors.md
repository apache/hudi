# Vendors

The following vendors provide managed services, cloud platform integrations, or commercial support for Apache Hudi. Vendors are listed alphabetically; inclusion on this page is for the convenience of the community and does not imply endorsement by the Apache Software Foundation or the Apache Hudi project.

To add or update a listing, please [open a pull request](https://github.com/apache/hudi/tree/asf-site/website/src/pages/vendors.md) or reach out on the [dev mailing list](mailto:dev@hudi.apache.org).

## Alibaba Cloud

Alibaba Cloud E-MapReduce ships with Apache Hudi support, and Hudi tables can be stored on [Alibaba Cloud OSS](/docs/oss_hoodie). Alibaba Cloud engineers are long-time contributors to the project.

[alibabacloud.com](https://www.alibabacloud.com/help/en/emr/emr-on-ecs/user-guide/hudi/)

## Amazon Web Services

Amazon EMR includes Apache Hudi out of the box, and Hudi tables on [Amazon S3](/docs/s3_hoodie) can be queried from Amazon Athena and Amazon Redshift Spectrum, with catalog integration via AWS Glue.

[aws.amazon.com](https://aws.amazon.com/emr/features/hudi/)

## ByteDance

ByteDance runs one of the largest Apache Hudi deployments in the world and offers Hudi through Volcano Engine's LakeHouse Analytics Service (LAS) and E-MapReduce products.

[volcengine.com](https://www.volcengine.com/docs/6491/198105)

## Google Cloud

Google Cloud Dataproc includes Apache Hudi, Hudi tables can be stored on [Google Cloud Storage](/docs/gcs_hoodie), and BigQuery integrates with Hudi tables through the [BigQuery integration](/docs/gcp_bigquery).

[cloud.google.com](https://cloud.google.com/dataproc/docs/concepts/components/hudi)

## Huawei Cloud

Huawei Cloud MRS (MapReduce Service) provides Apache Hudi as part of its data lake offering, with Hudi used as the storage layer for its FusionInsight lakehouse solutions.

[support.huaweicloud.com](https://support.huaweicloud.com/intl/en-us/productdesc-mrs/mrs_08_0083.html)

## Onehouse

Onehouse provides a fully managed universal data lakehouse service built on Apache Hudi, founded by the original creators of the project. Onehouse offers commercial support for Apache Hudi and contributes heavily to its development.

[onehouse.ai](https://www.onehouse.ai/solutions/managed-hudi)

## Tencent Cloud

Tencent Cloud EMR supports Apache Hudi, and Hudi tables can be stored on [Tencent Cloud Object Storage](/docs/cos_hoodie).

[tencentcloud.com](https://www.tencentcloud.com/document/product/1026/35587)
