Spark Connect is reachable inside the cluster at:
  {{ include "hudi-spark-connect.fullname" . }}.{{ .Release.Namespace }}.svc:{{ .Values.service.port }}

For local clients:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "hudi-spark-connect.fullname" . }} 15002:{{ .Values.service.port }}

Foundry ADBC URI (client-side driver required):
  spark://localhost:15002?api=connect&auth_type=none&tls=false

This endpoint has no client authentication/TLS configured. Use only on trusted
networks; ClusterIP alone is not an authorization boundary. Do not publish it
through an ingress/LoadBalancer without authentication and access controls.
One shared local-mode Spark driver serves all sessions. Restarting it loses
sessions, not tables in the external metastore/object store.
